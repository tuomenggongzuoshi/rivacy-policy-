版本：V1.1　更新日期：2026年11月05日　生效日期：2026年11月05日

本应用《江湖·启行录》（以下简称“本游戏”）由个人开发者（以下简称“我们”）提供运营。我们非常重视保护用户（以下简称“您”）的个人信息和隐私。您在使用本游戏时，我们特制定本《隐私政策》。

请您在使用本游戏前认真阅读本隐私政策，特别是加粗或单独提示的条款。您勾选同意并开始使用本游戏，表示您已理解并同意我们按照本政策处理相关信息。本政策仅适用于本游戏；第三方 SDK 的信息处理行为同时受其自身隐私政策约束。

一、我们如何收集和使用您的个人信息

（一）我们收集哪些信息

1. TapTap 账号登录

当您主动点击 TapTap 登录并授权时，我们通过 TapSDK 获取您的 TapTap 账号标识（OpenID）、昵称、头像（以您实际授权的范围为准）。这些信息用于识别您的账号、绑定本地游戏存档、切换账号以及校验兑换码归属。我们不会通过该登录获取您的手机号、通讯录、位置信息。

2. 本地游戏存档

本游戏的角色昵称、游戏进度、门派/武学/地图/邮件/设置、已使用的兑换码记录等存档数据，默认仅保存在您的设备本地，不会上传至我们自建的服务器。卸载应用或清除应用数据会导致本地存档全部丢失且无法恢复，请知悉。当前为封闭测试版本时，测试结束或版本更新可能清除测试数据，具体以游戏内测试公告为准。

3. 兑换码

当您使用兑换码时，我们会将您输入的兑换码、本地角色标识（角色 ID）、账号标识及请求签名提交至 TapTap 开发者服务（TDS）进行有效性校验和防重复校验，以便向您的账号发放奖励。我们不会收集您的支付信息或银行卡信息。

4. 设备与网络信息

为实现登录、账号安全、防沉迷校验和网络请求，TapSDK 可能收集设备型号、操作系统版本、网络类型、IP 地址等信息。我们自身不单独建立服务器保存这些信息，相关处理适用 TapSDK 的隐私政策。

5. 实名认证与防沉迷（如本版本启用）

本游戏通过 TapSDK 的实名认证与防沉迷能力，按照国家关于未成年人网络游戏防沉迷的规定对游玩时段、时长进行限制。实名认证所需的姓名、身份证件信息由 TapSDK 处理，我们不会获取、保存您的身份证件原文。若您未完成实名认证，或经校验属于未成年人，游戏将按照适用法规限制游玩时段和时长。

6. 客服与反馈

当您通过邮箱、问卷或游戏内反馈入口联系我们时，我们会收到您主动提供的联系方式、账号标识、问题描述、设备信息或日志。这些信息仅用于定位问题、回复您和改善游戏体验；超出处理目的所需期限后，我们将删除或匿名化处理。

（二）设备权限调用情况

本游戏使用网络权限，用于 TapTap 登录、兑换码校验、防沉迷校验和必要的网络请求。本地存档保存在系统为应用分配的应用沙盒内，不额外申请访问您其他文件的权限。

本游戏不会主动申请相机、麦克风、定位、通讯录等权限。如系统或第三方 SDK 因特定功能需要其他权限，会以系统授权弹窗和相应 SDK 说明为准；您可以拒绝授权，但相关功能可能无法使用。您也可以在手机系统设置中关闭网络权限，关闭后登录、兑换码和防沉迷功能将无法正常工作。

（三）我们如何使用您的个人信息

我们仅为以下目的使用相关信息：

  • 提供游戏登录、存档绑定、账号切换和基础游玩功能；
  • 校验并发放兑换码奖励；
  • 落实实名认证和未成年人防沉迷要求；
  • 保障游戏运行与账号安全，处理您主动提交的客服反馈；
  • 履行法律法规规定的义务。

我们不会将您的个人信息用于广告推送、用户画像或对外出售，也不会生成对外发布的个人统计信息。

（四）无需取得同意的法定情形

根据相关法律法规及国家标准，以下情形中，我们可能收集、使用您的相关信息而无需事先征得您的授权同意：

  • 与我们履行法律法规规定的义务相关的；
  • 与国家安全、国防安全直接相关的；
  • 与公共安全、公共卫生、重大公共利益直接相关的；
  • 与刑事侦查、起诉、审判和判决执行等直接相关的；
  • 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
  • 所涉及的个人信息是个人信息主体或监护人自行向社会公众公开的；
  • 根据个人信息主体要求签订和履行合同所必需的；
  • 从合法公开披露的信息中收集个人信息的；
  • 维护所提供的产品或服务的安全稳定运行所必需的，如发现、处置产品或服务的故障。

二、我们如何保存您的个人信息

1. 游戏角色、进度和设置等存档保存在您的设备本地，保存期限以您不卸载、不清除应用数据为前提。

2. TapSDK 处理的账号、实名、设备和网络信息，其保存期限和存储地点以 TapSDK 隐私政策及适用法律法规为准。

3. 兑换码请求仅用于校验和发奖，我们不在自建服务器长期保存兑换码请求内容；本地仅保存已使用兑换码的记录，用于防止重复兑换。

4. 客服与反馈信息在处理完毕后删除或匿名化，最长不超过实现处理目的所需的合理期限。

5. 据我们目前所知，本游戏及所选第三方服务在中国境内处理相关信息；如未来发生跨境传输，我们将依法另行告知并取得必要的同意。

三、我们如何共享、转让、公开披露您的个人信息

1. 为实现登录、兑换码和防沉迷功能，我们仅会向以下第三方提供实现功能所必需的信息：TapSDK（登录、实名与防沉迷）、TapTap 开发者服务 TDS（兑换码校验）。

2. 我们不会出售您的个人信息，也不会主动向无关第三方共享、转让或公开披露您的游戏存档。

3. 仅在法律法规要求、司法机关或行政机关依法强制要求的情况下，我们才会对外提供必要信息。

4. 如发生合并、分立、资产转让等情形，我们将要求承接方继续受本政策约束，否则重新取得您的同意。

五、我们如何保护您的个人信息

1. 我们采取合理可行的措施保护您的信息，包括使用 HTTPS 传输、最小化收集、将存档限制在应用沙盒内，并限制内部访问权限。

2. 请您知悉，移动设备与网络环境并非百分之百安全，我们无法保证绝对安全；若发生个人信息安全事件，我们将按照法律法规要求，通过游戏内公告、页面提示或您预留的联系方式告知相关情况。

3. 请您妥善保管设备和解锁密码，避免他人未经授权访问您的本地存档。

六、您如何管理您的个人信息

1. 访问与更正：角色昵称可在游戏内修改；本地存档可在游戏内查看。如您需要了解我们处理您信息的情况，可通过本政策预留邮箱联系我们。

2. 删除：您可以清除应用数据或卸载应用删除本地存档；已使用的兑换码记录会随本地数据一并删除。删除后无法恢复。

3. 撤回同意：您可以在系统设置中关闭网络权限或停止使用本游戏，但关闭网络后登录、兑换码和防沉迷功能将无法使用。撤回同意不影响此前基于同意已进行的处理。

4. 账号与注销：本游戏不建立独立的线上账号体系，游戏进度为本地存档；TapTap 账号的注销、授权管理请通过 TapTap 客户端或 TapTap 官方渠道办理。卸载本游戏或清除应用数据即可删除本地游戏数据。

5. 联系请求：如您有访问、复制、更正、删除或撤回同意等诉求，可发送邮件至本政策第九节邮箱。为保障安全，我们可能在处理前核验您的身份；一般情况下将在十五个工作日内回复。对于无端重复、超出合理限度或依法无需响应的请求，我们有权拒绝。

以下情形，我们将无法响应您的请求：

  • 与我们履行法律法规规定的义务相关的；
  • 与国家安全、国防安全直接相关的；
  • 与公共安全、公共卫生、重大公共利益直接相关的；
  • 与刑事侦查、起诉、审判和执行判决等直接相关的；
  • 我们有充分证据表明个人信息主体存在主观恶意或滥用权利的；
  • 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；
  • 响应请求将导致个人信息主体或其他个人、组织的合法权益受到严重损害的；
  • 涉及商业秘密的。

七、我们如何处理未成年人的个人信息

1. 本游戏不专门面向未成年人。若您为未满 14 周岁的儿童，请在监护人阅读并同意本政策后使用本游戏；若您为已满 14 周岁未满 18 周岁的未成年人，请在监护人同意或指导下使用。

2. 本游戏按照适用法规接入实名认证与防沉迷能力，对未成年人的游玩时段和时长进行限制。未成年人的监护人可通过本政策第九节联系方式了解、更正或删除相关信息。

3. 如我们发现自己在未事先获得可证实的监护人同意的情况下收集了儿童个人信息，将尽快删除相关数据。若您是监护人，发现未成年人未经您同意使用本游戏，请联系我们。

八、本隐私政策如何更新

1. 我们可能因功能变化、法律法规更新或第三方服务调整而修改本政策，更新后的政策将在本页面发布，并标明更新日期和生效日期。

2. 对于重大变更（如新增收集信息类型、改变处理目的、新增第三方共享），我们会在游戏启动或版本更新时通过弹窗、公告等方式提示，并在依法需要时重新征得您的同意。

3. 未经您明确同意，我们不会削减您按照本政策所应享有的权利。
